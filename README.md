# AG-60517 · In-App Event «AdGuard v5 is here» — Keyshape-анимации

Лёгкая цикличная анимация для App Store In-App Event (Jira: AG-60517). Два проекта Keyshape,
которые открываются в [Keyshape](https://keyshapeapp.com) и досматриваются/правятся руками.

- **AG-60517 Event Card 16x9.keyshape** — Event Card 1920×1080 (бюст Агнара с вороном)
- **AG-60517 Event Details 9x16.keyshape** — Event Details 1080×1920 (Агнар в полный рост с мечом)
- `index.html` + `previews/*.svg` — браузерные SMIL-копии ключей для быстрого просмотра (тот же луп 20 c)

## Концепция движения (луп 20 c)

| Время | Что происходит |
| --- | --- |
| 0–1 c | статичный кадр (камера 1.0) |
| 1–4 c | камера: наезд 1.0 → 1.12 (9:16 — до 1.10) |
| 4–6 c | замер |
| 6–8.5 c | камера: второй наезд до 1.20 (9:16 — 1.16) |
| 8.5–10.5 c | замер |
| 10.5–17.5 c | медленный отъезд к 1.0 |
| 17.5–20 c | статичный хвост → луп |

Параллельно, независимо от камеры:

- **Дыхание Агнара** — 5-секундный цикл (вдох 2.5 c / выдох 2.5 c), мягкий `scaleY`
  +1.2% (16:9) / +1.0% (9:16) от пивота внизу груди. Без поворотов и горизонтального шатания.
- **Свечение** (зелёный эллипс из Figma) — пульс в такт дыханию: opacity 0.82 ↔ 1.0.
- **Блики** — короткие звёздочки-вспышки: корона ~5 c, наплечник ~9.5 c (16:9) /
  клинок ~9.5 c и гарда ~15 c (9:16). Появление 0.35 c, затухание ~1 c, лёгкий рост масштаба.
- **UI** (бейдж, заголовок, подпись, чипы) — статичен, лежит поверх камеры.

## Риги в Keyshape (Object Tree)

| Слой | Пивот | Каналы |
| --- | --- | --- |
| `Camera` | лицо Агнара (фокус пролёта) | Scale: 8 ключей, 0–20 c |
| `Agnar-breathing` | низ груди по центру персонажа | Scale (только Y): 9 ключей, период 5 c |
| `Glint-crown` / `Glint-pauldron` / `Glint-blade` / `Glint-hilt` | центр звезды-блика | Scale + Opacity, разовые вспышки |
| `Glow` | — | Opacity: 9 ключей в такт дыханию |
| `Badge`, `Title`, `Subtitle`, `Feature-chips` | — | статика (без каналов) |

ВCAMере вложен `Agnar-breathing` (и блики внутри него) — блики едут вместе с дыханием груди.

На таймлайне расставлены маркеры (Камера: наезд/замер/отъезд, Блик: …) — навигация по фазам.

## Структура проекта

```
assets/
  meta.json          — координаты кусков (из Figma get metadata, относительно кадра)
  16x9/, 9x16/       — PNG-куски: character (2x), glow (границы = эллипс + blur 1000),
                       badge, title, subtitle, chips (2x)
tools/
  fetch_figma.py     — метаданные + REST-экспорт кусков (python3 tools/fetch_figma.py --export)
  build.py           — сборка .keyshape + SMIL-превью + index.html
  validate.py        — валидация .keyshape (zip, XML, тайминги, каналы)
previews/            — SMIL-превью для браузера
index.html           — лендинг с превью и ссылками на скачивание
```

Внимание: `tools/build.py` перезаписывает .keyshape — ручные правки из Keyshape при пересборке
теряются (механизма learn/overrides, как в проекте «AG Store image animation (2026)», здесь нет).

## Формат .keyshape (проверено по keyshapeapp.com/file-format)

`abs-key-times` в секундах; `ks:playRangeIn/Out` в миллисекундах; `timing-functions` = ключи − 1;
`repeat-end="indefinite"`; scale/rotate исполняются от пивота группы (позиция группы = пивот,
контент рисуется относительно него через обратный translate-обёртки).
